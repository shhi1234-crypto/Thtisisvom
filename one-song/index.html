PROJECT

회차와 곡

저장되지 않은 변경이 있으면 상단 상태에 표시됩니다. 줄 번호는 현재 순서에 맞춰 01부터 자동으로 다시 매깁니다.

SINGERS

참여자와 기본 색

한 곡에 최대 4명까지 등록할 수 있습니다. 성별을 고르면 기본 글자색과 추가 보컬 배경색이 적용되며, 색상표에서 조정할 수 있습니다.

시현의 성별 색상 분류는 아직 확인되지 않았습니다. 실제 배분에 적용하기 전에 직접 설정해 주세요.

SELECTION TOOLS

선택 구간에 파트 지정

가사 글자를 드래그해 선택하세요. 선택하지 않으면 활성 줄 전체에 적용됩니다.

참여자
선택한 글자 색

직접 지정한 색은 파트 정보와 별도로 저장됩니다. 동성 동음은 볼드로 구분할 수 있고, 밑줄이나 테두리는 사용하지 않습니다.

LYRICS

가사와 파트

각 가사는 실제 텍스트로 편집됩니다. 개인 파트가 바뀌는 곳은 줄을 나눠 입력하세요. 구절 메모는 가사를 입력하면 해당 문구를 찾아 표시합니다.

현재 곡의 가사 텍스트가 아직 없습니다. 줄에 가사를 붙여 넣으면 구절 메모가 해당 글자 범위에 연결됩니다.

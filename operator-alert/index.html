운영 알림 등록

처음 한 번만 하면 됩니다. 사용하는 휴대폰에 맞춰 진행해주세요.

1이 링크를 Safari로 엽니다.
카카오톡 안에서 열렸다면 우측 하단 또는 상단 메뉴에서 Safari로 열기를 눌러주세요.
2Safari 하단 가운데의 공유 버튼 (네모 위 화살표)을 누릅니다.
3메뉴를 아래로 내려 홈 화면에 추가 → 우측 상단 추가를 누릅니다.
4아이폰 홈 화면에 생긴 보라색 VOM 운영 아이콘을 다시 엽니다.
5아래 이 기기에서 알림 받기를 누르고, 아이폰 팝업에서 허용을 선택합니다.
6테스트 알림 보내기를 누른 뒤 잠금화면 또는 상단 알림창에 VOM 운영 알림이 뜨는지 확인합니다.
1이 링크를 Chrome으로 엽니다.
카카오톡 안에서 열렸다면 메뉴에서 Chrome으로 열기를 눌러주세요.
2아래 이 기기에서 알림 받기를 누릅니다.
3알림 권한 팝업에서 허용을 누른 뒤, 테스트 알림 보내기로 도착 여부를 확인합니다.
안내 이미지 열기 · 길게 눌러 저장
등록 정보를 확인하는 중입니다.
등록 후에는 따로 홈페이지를 열지 않아도 운영 마감 알림이 폰으로 옵니다. 폰을 바꾸거나 알림을 껐다면 이 링크로 다시 등록하면 됩니다.
